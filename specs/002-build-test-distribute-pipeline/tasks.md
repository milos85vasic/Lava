## Superpowers Execution

### Execution Discipline by Marker

- **[TDD]**: RED-GREEN-REFACTOR. Write test → run (must fail) → implement → run (must pass). T004–T007, T010–T013, T050–T053 are this feature's three TDD cycles; per `plan.md`, none may be skipped given their blast radius (precondition safety, evidence-validation correctness, submodule-advance correctness).
- **[SUBAGENT]**: Dispatch to a subagent where available — T015–T019, T021–T028, T036/T037, T044/T045, T059/T060 are the natural batches.
- **[REVIEW]**: Pause execution. Present completed work to user. Wait for explicit approval before continuing. T012, T040, T041, T048, T054, T062 are review gates — three of them (T040, T041, T048) are constitutional amendments and MUST NOT be treated as routine code review.
- **[P]**: Launch parallel tasks where possible using the Task tool.

### Checkpoint Protocol

At every phase boundary:
1. Summarize what was completed in this phase.
2. Run applicable tests (this feature's own hermetic tests, plus the relevant `quickstart.md` scenario).
3. Report test results.
4. Ask user: "Phase [N] complete. Proceed to Phase [N+1]?"
5. Only continue after explicit user approval.

## Implementation Strategy

**MVP scope**: User Story 1 alone (Phases 1, 2, 3) — a working build+test+evidence pipeline with zero distribution or repository-closure behavior is independently valuable and ships zero constitutional risk (no amendment required). This is the natural first milestone.

**Incremental delivery after MVP**:
1. User Story 2 (install/boot + live-verify) — still zero constitutional risk, closes the "tests pass but the running system was never proven" gap.
2. User Story 3 (distribute + docs) — requires the T040/T041 constitutional amendment; do not start US3's distribute implementation before that amendment is reviewed and merged.
3. User Story 4 (repository closure) — requires the T048/T049 constitutional amendment; highest-blast-radius component (`advance-all-submodules.sh`) gets its own dedicated review gate (T054) independent of the amendment's own review.

Each story delivers a complete, independently demonstrable increment per its own `quickstart.md` scenario — the full pipeline (all four stories wired together, Phase 7) is the final assembly, not a separate design.
