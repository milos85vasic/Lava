# Lava-API-App-0.1.0-1 — 2026-06-02 (first distribution)

**Previous published:** none — this is the first distribution of the standalone
on-device Lava API server app.

## What's new for testers

- **Brand-new "Lava API" Android app** (`digital.vasic.lava.api`; debug variant
  suffix `.dev`). It runs the full lava-api-go server **in-process on your
  device**, served over HTTPS on the local network and advertised over mDNS
  (`_lava-api._tcp`, TXT `engine=go,platform=android,storage=sqlite`) so other
  devices — including the Lava client's "Choose your API" screen — discover it.
- Foreground service with **start / stop / restart** notification controls; a
  per-install auth-key store (EncryptedSharedPreferences); SQLite storage backend.
- Shares the **same signing keystore** as the client app; `minSdk 23`.
