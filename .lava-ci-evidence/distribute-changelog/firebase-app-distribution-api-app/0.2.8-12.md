## Lava-API-App-0.2.8-12 — 2026-06-14 (Foreground service no longer crashes after long uptime — dataSync → specialUse)

**Previous published:** Lava-API-App-0.2.7-11 (debug+release).

- **The on-device API no longer crashes after long uptime** — the foreground service used
  the `dataSync` type (Android 14+ caps it at ~6h cumulative → crash). Now uses
  `specialUse` (no time budget) + graceful `onTimeout` stop instead of crashing. Embedded
  provider catalogue + search unchanged from 0.2.7-11.

Play note: specialUse carries a free-form Play Console review justification (manifest property).
