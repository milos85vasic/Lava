# Lava-API-App-0.2.13-27 — embedded engine: permanent §6.AC telemetry (parity bump, api-app unaffected by LVA-098)

**Previous published:** Lava-API-App-0.2.13-26.

- Embedded `lava-api-go` engine (`liblavaapi.so`) picked up the same-cycle permanent §6.AC diagnostic logging (auth-blob header-presence/hash + global request/status logging). A genuine embed-source change, not a needless re-distribute.
- api-app itself is NOT affected by the LVA-098 bug (that bug is `:app`-client-only; api-app uses a different auth-key delivery path, `ApiKeyProvider`).
- A build-hygiene incident (a corrupted APK from running two concurrent Gradle builds against the same monorepo) and a JVM GC-thread crash under R8 minification at the default heap size were both found + fixed during this cycle's gate — see the test-evidence file for details.
