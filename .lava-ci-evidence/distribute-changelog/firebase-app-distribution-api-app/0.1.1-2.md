## What's new for testers

- **Proper launcher icon** — the standalone Lava API app now uses the same adaptive
  launcher icon as the Lava client (the colored Lava logo foreground + the background
  hint color, per-density PNGs + `mipmap-anydpi-v26` adaptive icon with a monochrome
  layer). Replaces the placeholder vector icon shipped in 0.1.0-1.
- **Debug variant named "Lava API DEV"** — the `.dev` debug build now shows a `DEV`
  name suffix on the launcher (via a `src/debug` `api_app_name` override), mirroring the
  client's "Lava DEV" convention, so the debug + release installs are distinguishable.
- No functional/server changes versus 0.1.0-1 — icon + naming only.
