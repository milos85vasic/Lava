## Lava-Android-1.3.8-1065 — 2026-06-14 (Search fixed + no duplicate servers + select-all providers + password show/hide)

**Previous published:** Lava-Android-1.3.7-1064 (debug+release).

- **Search works again across your providers** — searching via the on-device API no
  longer fails with "Something went wrong" (the app now authenticates every per-provider
  request with the API's per-instance key + the correct LAN client). Fixes RuTracker, YTS,
  Kinozal and all providers served by the on-device / LAN API.
- **No more duplicate servers in Settings** — the chosen server appears once, not twice.
- **Select-all / Deselect-all providers** in onboarding "Pick your providers".
- **Standard password field** — masked by default + show/hide (eye) toggle.

Each fix has a reproduction test + a device-run Challenge that passed on a Genymotion
Pixel 9 / API 35 VM. Paired with on-device API app 0.2.8-12.
