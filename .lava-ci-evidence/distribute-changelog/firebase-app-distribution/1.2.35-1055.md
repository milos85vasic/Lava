## User-visible changes since 1.2.34 (1054)

- **"Choose your API" onboarding now has two sections.** Alongside the existing
  "On your network" local-discovery list, a new **"Cloud / remote server"**
  section lets you connect to a Lava-API hosted elsewhere: type a server
  address + port and tap **Add server**, or pick a pre-installed default. A
  placeholder default (`https://lava.app:7777`) is shown until a real public
  origin exists. You still choose exactly one API instance to continue, and the
  selection runs the same connectivity probe before advancing.
