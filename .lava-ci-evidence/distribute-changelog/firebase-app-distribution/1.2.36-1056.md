# Lava-Android-1.2.36-1056 — 2026-06-02

**Previous published:** Lava-Android-1.2.35-1055 (debug + release, 2026-06-01).

## What's new for testers

- **On-device API support in the client.** The network-discovery list now parses
  and labels API instances advertised with `platform=android` (a Lava API running
  on another phone/tablet on your LAN). The onboarding **"Choose your API"** step
  labels those on-device instances distinctly, and **Settings → "Run the API on
  this device"** lets you install or launch the new standalone **Lava API** app
  (`digital.vasic.lava.api`) — or, when it is not installed, opens its download
  link. (commit 199f1404 / merge 7fce7cf9)
- This is the **client half** of the new on-device API capability. The **server
  half** ships separately as the standalone Lava API app (Lava-API-App-0.1.0-1),
  distributed for the first time this cycle.
- Fresh signed **debug + release** build with a rotated auth pepper, shipped via
  the §6.AA two-stage flow (debug first, release after on-device verification).
- lava-api-go unchanged this cycle → stays 2.3.23-2323.

## §6.Z device-gate status — BLOCKED (client distribute DEFERRED)

The C00 (cold-start) + C01 (launch) client gate was ATTEMPTED but is infra-BLOCKED
this cycle: the Pixel_8/API35 emulator failed to reach `sys.boot_completed` across
five cold-boot attempts (boot windows 5m→15m), on both a loaded and a quiet host
and on a freshly-wiped AVD — root-cause hypotheses (Kaspersky AV saturation, memory
pressure, qemu zombies, AVD-overlay corruption) each investigated and addressed,
none resolved it. The emulator booted fine on this same host at 11:35 today, so the
wedge developed mid-session and most likely clears only with a host reboot
(operator-only per the Host Stability Directive). Forensics:
`.lava-ci-evidence/sixth-law-incidents/2026-06-02-emulator-boot-wedge.json`.

Per §6.Z (no distribute without an EXECUTED green gate against the artifact), the
**client 1.2.36-1056 distribute is DEFERRED** until a bootable gate host is
available. The version bump + rotated pepper + built APKs stand ready; only the
distribute step waits. The new api-app (Lava-API-App-0.1.0-1) shipped its debug
stage this cycle on independently-solid transferred evidence.
